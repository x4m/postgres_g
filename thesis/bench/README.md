## Измеренные характеристики дисков g2

QD=1, `dd` с `O_DIRECT`, блок 1 МиБ, по два прогона:

| | посл. чтение | посл. запись | случайное 4К, QD1 |
|---|---|---|---|
| `vda` корневой | 231 МБ/с | 169–200 МБ/с | 7,7 МБ/с (~1970 IOPS, ~500 мкс) |
| `vdb` nrd `/mnt/nvme` | 115 МБ/с | 84–92 МБ/с | 10,6 МБ/с (~2700 IOPS, ~370 мкс) |

Паспорт nrd: 28000/5600 IOPS, 110/82 МБ/с. Измерения совпадают с паспортом по
полосе; IOPS при QD=1 упирается не в диск, а в задержку.

**Что из этого следует для методики.** При странице 8 КиБ паспортная полоса
110 МБ/с даёт потолок около 14 000 страниц/с — и для последовательного, и для
случайного чтения, если очередь достаточно глубока. То есть на этом диске
разница между произвольным и последовательным доступом определяется не
носителем, а **глубиной очереди**: одиночное случайное чтение даёт ~2700
страниц/с, последовательное — ~14 000.

Отсюда распределение задач:

- **`vda`, корневой** — эксперименты по времени построения индекса: там
  упирается в последовательную запись, а её на корневом вдвое больше.
- **`vdb`, nrd** — эксперименты со стороны запросов и сопровождения, где важен
  произвольный доступ и где виден эффект упреждающего чтения. Это удачная
  площадка для P6: диск, у которого потолок IOPS высок, а полоса низка, прямо
  показывает, что даёт переход от QD=1 к пакетной выдаче запросов.
- **Число обращений к страницам остаётся первичной метрикой** в обоих случаях:
  оно переносимо и сопоставляется с моделью главы 2 напрямую.

## Планируемые сборки

Для эксперимента с управляемой кластеризацией (см. `../plan/60-pvldb.md`, п. 2)
нужны две сборки из одного дерева, различающиеся ровно одним коммитом:

- `bench-naive` — `f1ea98a7975^`, разбиение по заполнению страницы;
- `bench-picksplit` — `f1ea98a7975`, разбиение через `picksplit` на буфере.

Построение вставкой измеряется на той же сборке через класс операторов без
функции поддержки сортировки (опорная функция 11 не объявлена) — это
исключает влияние различий между версиями.

Исходники: `~/pgsrc`, клон был поверхностным (399 коммитов), разворачивается
в полный.
