% поиска не переиспользовало страницы вовсе, и при нагрузке «вставка в новую

% Результат: <числа>. Реализация в PostgreSQL, выпуски 12, 13, 18.
% Отдельный вклад: разбор случая, в котором опубликованный и отрецензированный
% алгоритм снижения гранулярности блокировок был отменён по результатам
% эксплуатации.

\section{Safe reuse condition}

% Сканирование, начатое до удаления, может обратиться к странице позже.

% Изложение: алгоритм снижения гранулярности блокировок при сборке мусора в
% обратном индексе был опубликован и отрецензирован (JPCS 2018). Через полтора

% именно она даёт основной эффект.

% системы, и опровергаются только эксплуатацией. Отсюда два практических
% вывода: (1) публикация о конкурентном алгоритме должна сопровождаться
% указанием предпосылок в проверяемой форме; (2) свойства, не проверяемые
