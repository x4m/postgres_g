## Правила

- Ни одно число не переносится из переписки или из прежних публикаций без
  перепроверки на актуальном выпуске; исторические значения приводятся с явной
  пометкой, к какой версии относятся.
- Каждый результат сопровождается идентификатором коммита и ссылкой на
  публичное обсуждение (`thread-*` в `refs.bib`).
- Вместе со временем построения всегда приводится время выполнения запросов и
  перекрытие ключей: по (2) стоимость поиска можно ухудшить, улучшая построение.
- Отменённые результаты не замалчиваются: разбор отката — отдельный раздел
  (p2, §7).
